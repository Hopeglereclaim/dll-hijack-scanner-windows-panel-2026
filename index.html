// Conceptual Overview

What is Dll Hijack Scanner Windows?

A fast, dependency-free Windows toolkit oriented around dll hijack scanner windows. It walks directory trees, inspects PE imports, and surfaces actionable paths for research workflows.

“Find the missing link in the execution chain.” Static analysis first — less noise than raw ProcMon dumps.

// Quick Start — CLI

Command line

HydraSoft.exe — options
HydraSoft.exe --path <dir> [options]

--path <dir>               # Directory to scan (required)
--output <file>            # .json or .csv (default stdout)
--image-type any|x86|x64   # Architecture filter
--rate any|best|good|bad   # Complexity rating
--write-perm               # Writable dirs only
